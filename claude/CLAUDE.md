# グローバルメモリ(全プロジェクト共通)

このファイルは `~/.claude/CLAUDE.md` として読み込まれ、Claude Code の
すべてのプロジェクトで適用される。内容は自分好みにカスタマイズすること。

## 言語

- 応答は日本語で行う。コード内の識別子・コメントは英語でよい。
- コミットメッセージと PR タイトル・本文は英語で書く。

## コーディング方針

- 既存コードのスタイル(命名・フォーマット・コメント密度)に合わせる。
- 変更は求められた範囲に留め、無関係なリファクタリングを混ぜない。
- 破壊的な操作(force push、ファイル削除、履歴書き換え)は実行前に必ず確認を取る。

## Git

- コミットは意味のある単位で分け、メッセージは Conventional Commits 形式
  (`feat:` / `fix:` / `docs:` / `chore:` など)を使う。
- main / master ブランチには直接コミットせず、作業ブランチを切る。

## その他

- 不明点を推測で進めず、判断が分かれる場合は選択肢を提示して確認する。
